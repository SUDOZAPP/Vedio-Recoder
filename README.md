# SUOU Video Recorder v4.4.6.7

**Windows 11／Chrome／Microsoft Edge｜全集單檔錄製版｜Cloudflare Pages**

SUOU Video Recorder 是以瀏覽器分頁畫面擷取為基礎的錄影工具，可搭配 **SUOU Desktop AutoEpisode v4.4.6.6** 擴充功能，在影片集數切換時持續錄製。本版新增「EP1～最後一集合成同一段錄影」模式：中途不逐集下載，到最後一集結束才完成一份 WebM 檔案。

> **版本狀態**：v4.4.6.6 的自動換集與逐集錄影已在使用者電腦測試成功（至少 EP1→EP4，且 EP1、EP2 音訊與完整性正常）。**v4.4.6.7 的全集單檔長時間錄製仍待實機驗證**。請先用 2～3 集測試。

## 主要功能

- **全集單檔錄影**：EP1 → EP2 → … → 最後一集，保持同一個 `MediaRecorder`，不在每集結束時拆檔。
- **自動換集**：由已安裝的 Desktop AutoEpisode **v4.4.6.6** 控制與確認切換；Recorder 收到換集事件後繼續同一段錄製。
- **直接串流寫入 Windows 檔案**：錄影開始時只選擇一次儲存位置，錄影期間逐塊寫入，最後一集完畢才關閉檔案。
- **保留分集模式**：取消勾選全集單檔，即返回每集錄完分檔的舊流程。
- **錄音安全檢查**：延續 Audio Guard 的音軌偵測與測試功能；擷取時必須選取分頁音訊。
- **其他原有工具**：保留 Recorder 頁面中的影片檢視與剪輯相關區塊。

## 系統需求

| 項目 | 要求 |
|---|---|
| 電腦 | Windows 11（一般 Windows 桌面瀏覽器環境） |
| 瀏覽器 | 最新版 Chrome 或 Edge；直接寫入使用 File System Access API |
| 錄影器 | SUOU Video Recorder **v4.4.6.7** |
| 自動換集擴充功能 | **SUOU Desktop AutoEpisode v4.4.6.6**（維持已測試版本） |
| 部署方式 | Cloudflare Pages，或其他符合瀏覽器安全性要求的 HTTPS 靜態網站 |
| 磁碟空間 | 預留足夠存放整部影片的可用空間 |

**不需為瀏覽器錄影安裝 FFmpeg。** FFmpeg 可作為錄影完成後修復或剪輯影片的另外一項工具。

## 安裝部署

1. 將 `SUOU-Video-Recorder-v4.4.6.7-Single-File-Pages.zip` 上傳至原本提供 `https://recoder.sudoz.workers.dev/` 的 Cloudflare Pages 專案。
2. 若自行組裝檔案，將 `index.html` 放在部署網站根目錄。
3. 重新整理 Recorder：Windows 可使用 **Ctrl + Shift + R** 強制重整。
4. 保留已能正常自動換集的 **AutoEpisode v4.4.6.6** 擴充功能，不要同時啟用多個舊版本。
5. 在實際影片播放分頁確認擴充功能已指定該分頁、啟用換集，並填寫**已確認的最後集數**（例如確實共有 14 集才設定 14）。

## 安裝 SUOU Desktop AutoEpisode v4.4.6.4 Bridge Fix（舊版擴充功能）

`SUOU-Desktop-AutoEpisode-v4.4.6.4-Bridge-Fix.zip` 是 Windows Chrome／Edge 用的 **Manifest V3 擴充功能**，並非 Recorder 的 Cloudflare Pages 部署包。這個版本修正了 Recorder 網址 `https://recoder.sudoz.workers.dev/` 的橋接腳本注入、來源資訊同步與換集狀態診斷。套件內有 `manifest.json`、`background.js`、`recorder-bridge.js`、`video-watch.js`、`popup.html`、`popup.js` 等檔案。

> **版本相容性提醒：** 本節應要求保留 v4.4.6.4 的安裝紀錄。**目前建議使用、且已在 Windows 實際驗證 EP1→EP4 換集成功的版本是 v4.4.6.6**。若使用本版 Recorder v4.4.6.7 全集單檔模式，請優先搭配 **AutoEpisode v4.4.6.6**；不要為了安裝舊版而取代已正常工作的新版。尚未證實 v4.4.6.4 能與單檔模式完成端到端錄製。

### 1. 下載並解壓縮

1. 取得 `SUOU-Desktop-AutoEpisode-v4.4.6.4-Bridge-Fix.zip`。
2. 在 Windows 檔案總管按右鍵 → **全部解壓縮**，或用 7-Zip 解壓縮。
3. 找到解壓後內含 `manifest.json` 的資料夾：`SUOU-Desktop-AutoEpisode-v4.4.6.4`。**載入擴充功能時應選這個資料夾，不是 ZIP 檔，也不是外層下載目錄。**

### 2. 安裝到 Chrome 或 Edge

**Chrome：** 開啟 `chrome://extensions/`；**Edge：** 開啟 `edge://extensions/`。

1. 啟用右上角的 **開發人員模式**。
2. 若已有 SUOU 舊版擴充功能，先將它停用；**同時只啟用一個 AutoEpisode 版本**，避免重複點擊下一集。
3. 點選 **載入未封裝項目（Load unpacked）**。
4. 選取 `SUOU-Desktop-AutoEpisode-v4.4.6.4`（其中必須直接包含 `manifest.json`）。
5. 確認擴充功能列表顯示 `SUOU Video Lock & Auto Episode v4.4.6.4`，且開關已啟用。
6. 如需方便操作，可點選瀏覽器工具列的拼圖圖示，將 SUOU 擴充功能**釘選**。

### 3. 指定影片來源、啟動協作

1. 開啟真正播放影片的分頁，例如 `https://javday.app/videos/.../`，並確認影片能播放。
2. **先切換到影片分頁**，再按 SUOU 擴充功能圖示 → **指定目前分頁為來源**。不要在 `recoder.sudoz.workers.dev` 分頁按這個按鈕。
3. 確認 Popup 顯示正確的來源網址或分頁資訊，再選擇 **顯示影片頁面板**。
4. 在影片頁面板設定目前集數與**確定的最後集數**，啟用自動換集；最後集數設為 `0` 不等於知道何時停止。
5. 於另一個分頁開啟 `https://recoder.sudoz.workers.dev/`，開始錄影並在瀏覽器分享視窗選擇**同一個影片分頁**，同時啟用**分享分頁音訊**。
6. Recorder 的擷取來源和擴充功能控制來源是兩個設定，必須指向同一個影片分頁。

### 4. 檢查橋接功能與常見問題

| 狀況 | 排除方式 |
|---|---|
| 「尚未指定來源分頁」 | 在**影片頁**開啟擴充功能並按「指定目前分頁為來源」；檢查來源網址，不要指定 Recorder 頁面 |
| Recorder 已錄影，但 `active=false` | 代表自動監控可能尚未啟動；確認 Recorder/擴充功能版本及橋接狀態；**建議改用 v4.4.6.6**，該版已驗證 ARM 啟動流程 |
| Chrome 顯示擴充功能無效或載入失敗 | 確認選取的資料夾直接含 `manifest.json`，而非壓縮檔或上一層資料夾 |
| 自動換集重複錄 EP1 | 先停止長時間錄製，確認來源綁定、監控已啟動及 EP2 已實際載入 |
| 音訊未被錄進去 | 分享**瀏覽器分頁**並啟用**分享分頁音訊**；先試錄 30 秒回放 |
| 影片頁 Console 顯示 CSS、Logo、favicon 404 | 這些訊息本身不等於 SUOU 換集失敗，應以 SUOU 診斷和實際播放結果判斷 |

### 5. 更新到推薦版本 v4.4.6.6

如已安裝 v4.4.6.4，請先**停用**它，再解壓 `SUOU-Desktop-AutoEpisode-v4.4.6.6-ARM-Diagnostic.zip`，同樣以「載入未封裝項目」選取其中含 `manifest.json` 的資料夾。確認 v4.4.6.6 正常顯示來源與自動換集狀態後，才開始正式長片錄影。先以 EP1→EP2 測試，確定換集與音訊正常再繼續。

## 全集單檔錄製：操作步驟

1. 在 Chrome／Edge 開啟影片播放頁，確認播放器可以正常播放，且能手動換集。
2. 在影片頁設定自動換集，確認「目前集數」與「最後一集」正確。
3. 開啟 SUOU Recorder，勾選：
   - **「EP1～最後一集合成同一段錄影」**
   - **「直接串流寫入 Windows 檔案」**（推薦）
4. **關閉定時停止與實驗性的智慧片尾停止**，避免尚未到最後一集就提前結束。
5. 點擊「開始錄影」，先於 Windows 儲存視窗選擇 WebM 檔名與目的地；**全程只選這一次**。
6. 在瀏覽器分享畫面視窗選擇真正播放影片的 **Chrome／Edge 分頁**，並啟用「分享分頁音訊」。
7. 保持 Recorder 分頁及影片來源分頁開啟，不要重新整理 Recorder。待最後一集播放完並收到結束訊號後，錄影器才停止並完成單一 WebM 檔案。
8. 完成後實際播放檔案，檢查畫面、聲音、總片長及最後一集結尾。

### 錄影流程示意

```text
EP1 開始 ──→ EP2 ──→ EP3 ──→ … ──→ 最後一集結束
  │          │         │                 │
  └──────────┴─────────┴─────────────────┘
        同一段 MediaRecorder 持續錄製
                         ↓
               完成一份 WebM 檔案
```

## 模式比較

| 項目 | 全集單檔（本版新增） | 每集分檔（保留） |
|---|---|---|
| EP 間切換 | 自動 | 自動 |
| 每集停止錄影 | 否 | 是 |
| 每集跳出下載 | 否 | 可能，依下載設定 |
| 輸出檔案 | 一份全集 WebM | 多份分集影片 |
| 儲存時機 | 直接寫檔模式：開始時選位置，期間持續寫入，最後關檔 | 每集結束時輸出 |
| 中途出錯影響 | 可能影響整份全集檔案 | 通常影響當前分集 |

## 單檔儲存與檔案安全

- **推薦「直接串流寫入 Windows 檔案」**：透過支援的瀏覽器檔案 API 邊錄邊寫入磁碟，比累積數 GB 在瀏覽器記憶體通常更穩定；但**沒有保證不當機或不會超出磁碟容量**。
- 勾選直接寫檔時，**開始錄製便要選擇輸出位置**；到最後一集才完成檔案，不代表最後才詢問路徑。
- 不勾選直接寫檔時，可能在記憶體累積完整錄影資料，**長時間錄影有記憶體不足風險**。
- 錄影期間不要關閉或重新整理 Recorder 頁面；關閉瀏覽器、斷電或程式異常可能造成檔案不完整。
- 錄製結果以 **WebM** 為主；需要 MP4 時可於錄影後另行轉封裝，請勿將 WebM 單純改副檔名為 `.mp4`。
- 換集時可能錄到短暫緩衝、黑畫面或載入畫面；單檔模式**不會自動無痕移除這些片段**。

## 音訊檢查

1. 分享來源優先選擇「**瀏覽器分頁**」，而不是整個螢幕。
2. 確認分享視窗的「**分享分頁音訊**」已啟用，播放器本身也沒有靜音。
3. 開始長片前先做約 30 秒短錄並回放，確認實際輸出檔有聲音。
4. 音軌存在或音量條跳動，不等於成品一定有聲音；仍以檔案回放確認為準。

## 常見問題

**Q：EP1 結束後為何不再立即下載？**  
A：開啟全集單檔模式後，這是預期行為；全部完成後才關閉並完成唯一檔案。若需每集輸出，取消「全集單檔」。

**Q：還是跳出逐集儲存提示？**  
A：確認 Recorder 已更新到 v4.4.6.7，並已勾選「EP1～最後一集合成同一段錄影」。部署後執行 Ctrl + Shift + R，避免使用瀏覽器快取的舊程式。

**Q：錄影開始時就出現儲存視窗？**  
A：已勾選直接寫入磁碟時屬於正常行為，只需選擇一次，不會每集詢問。

**Q：畫面換集成功，但最後沒停止？**  
A：確認擴充功能設定的「最後一集」是實際集數而非 `0`；最後集結束訊號仍需實際測試。

**Q：錄完沒有聲音？**  
A：重新選擇瀏覽器分頁並開啟「分享分頁音訊」，先短錄回放確認，再開始全集錄影。

**Q：瀏覽器不支援直接寫入檔案？**  
A：使用受支援的桌面 Chrome／Edge HTTPS 頁面。也可取消直接寫檔改成最後一次下載，但長片有記憶體風險。

**Q：需要更新 Chrome／Edge 擴充功能嗎？**  
A：本 Recorder 版搭配先前已測試成功的 **AutoEpisode v4.4.6.6**；無須因單檔模式升級擴充功能。
